# ADR 0011 — Source-reference recommendations and bounded date exploration

Accepted following the user's approximate destination-local meeting and non-global cheapest amendments. No new platform, key, migration, paid provider call or automatic phase is required.

Strict confirmed results retain their original contracts. Separate reference results accept fresh structurally complete source offers whose numeric/display/exact fields agree and whose explicit cabin, party, route or baggage evidence does not contradict the request. Missing rights remain unknown. Meeting sums are sums of source reference amounts, not verified party-inclusive totals; flexible prices come from the selected return response, never summed outbound+return.

Offset-free valid ISO timestamps are compared as destination-local clocks under an explicit source-local assumption. No IANA zone is guessed, no UTC is manufactured and time_verified stays false. Same local arrival day, one/two/four/six-hour gap choices (default two hours), cheapest inside-gap references and nearest outside-gap alternatives are exposed separately. DST/source semantics remain unverified; references are not travel guarantees. Same-itinerary duplicates retain lower source prices; streaming top-five selection bounds retained memory. Existing confirmed UTC reducer is unchanged.

Flexible requests support exhaustive (legacy default) or heuristic with max_pairs1..8 (UI default3). Deterministic farthest-point sampling spans both date axes. Fresh same-owner saved complete references matching origin/destination/cabin/adults/currency/bag request and destination-local night range can seed neighboring +/-1 date samples on a subsequent explicit user request. Remaining slots sample uncovered space. Seeds guide sampling only, never serve as new live results. No local/global optimum guarantee or automatic second phase. One outbound branch per pair remains explicit.

Admission's owner/idempotency lookup precedes seed lookup. Resolved dates are immutable in the persisted plan; retries reuse it even if seeds expire/change. Legacy batches without strategy fields retain their original idempotency hash through a narrowly constrained compatibility path. Every selected child/operation is reserved atomically; insufficient budget rejects the whole selected plan rather than secretly narrowing it. Coverage distinguishes possible Cartesian pairs, selected pairs, searched pairs, reference cells and verified cells. Browser previews count/cost exactly, while admission may replace sample identities with seed neighbors.

Source evidence: [Actor README](https://apify.com/scrapercompany/google-flights-scraper) exposes timezone-free times without normative timezone semantics. Its published example also differs between rounded numeric/display price and price_exact; this implementation continues to exclude disagreements pending rounding semantics verification, rather than treating them as proven identical. Same-source agreement is not independent Google/airline price validation. Earlier live snapshots remain real source observations; no new fresh provider E2E is claimed for this scope.

Independent review resolved two P2s: expensive duplicate overwrite and Cartesian-product memory allocation. Final read-only review found no remaining P1/P2. Tests and installation qualification are indexed in docs/qa/reference-recommendations-2026-10-12.md.
